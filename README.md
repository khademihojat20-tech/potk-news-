# راهنمای راه‌اندازی پتک نیوز 🔨📰

## چیزی که ساخته شده
یک ربات پایتون که:
- هر روز ۴ بار (۸، ۱۲، ۱۶، ۲۰) فیدهای خبری اقتصاد و تکنولوژی را چک می‌کند
- خبرهای جدید را با هوش مصنوعی به فارسیِ روان و در قالب خبری بازنویسی می‌کند
- خودکار در کانال تلگرام «پتک نیوز» منتشر می‌کند
- از تکرار خبر جلوگیری می‌کند (حافظه‌ی seen.json)

شما فقط باید یک‌بار آن را روی یک سرور/کامپیوتر همیشه‌روشن راه‌اندازی کنید؛ بعد از آن کاملاً خودکار کار می‌کند و شما فقط ناظر خواهید بود.

## مرحله ۱ — ساخت ربات تلگرام
1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام بدهید.
2. دستور `/newbot` را بزنید و اسم و یوزرنیم دلخواه انتخاب کنید.
3. توکنی که می‌دهد را جایی کپی کنید (چیزی شبیه `123456:ABC-DEF...`).

## مرحله ۲ — ساخت کانال و افزودن ربات
1. یک کانال تلگرام به اسم «پتک نیوز» بسازید.
2. ربات ساخته‌شده را به عنوان **ادمین** کانال اضافه کنید (با دسترسی ارسال پیام).
3. اگر کانال پابلیک است، آیدی کانال همان `@یوزرنیم_کانال` است.
   اگر پرایوت است، باید عددی شبیه `-1001234567890` را از طریق ابزارهایی مثل @userinfobot پیدا کنید.

## مرحله ۳ — گرفتن کلید رایگان Gemini API
1. به [aistudio.google.com/apikey](https://aistudio.google.com/apikey) برو
2. با اکانت گوگل وارد شو
3. روی «Create API Key» بزن — نیازی به کارت اعتباری نیست
4. کلید ساخته‌شده را کپی کن

توجه: نسخه‌ی رایگان Gemini سهمیه‌ی روزانه دارد (کافی برای این ربات) و ممکن است داده‌های ارسالی برای بهبود مدل استفاده شوند؛ برای اخبار عمومی مشکلی ندارد.

## مرحله ۴ — نصب و تنظیم روی سرور
```bash
pip install feedparser requests google-genai schedule --break-system-packages

export TELEGRAM_BOT_TOKEN="توکن ربات شما"
export TELEGRAM_CHANNEL_ID="@petak_news"
export GEMINI_API_KEY="کلید Gemini شما"

python3 petak_news_bot.py
```

برای اینکه ربات همیشه در پس‌زمینه روشن بماند (حتی بعد از بستن ترمینال)، پیشنهاد می‌شود آن را با `systemd` یا `pm2` یا `screen`/`tmux` یا روی یک VPS ارزان اجرا کنید.

## سفارشی‌سازی
- **لیست منابع خبری**: در فایل `petak_news_bot.py`، متغیر `RSS_FEEDS` را ویرایش کنید و فیدهای دلخواه اقتصاد/تکنولوژی را اضافه یا حذف کنید.
- **ساعت انتشار**: متغیر `RUN_TIMES` را تغییر دهید.
- **تعداد خبر در هر نوبت**: متغیر `MAX_ITEMS_PER_RUN`.
- **لحن/قالب پست**: داخل تابع `rewrite_in_persian` پرامپت را می‌توانید ویرایش کنید (مثلاً هشتگ‌های ثابت، امضای خاص، و غیره).

## نکته درباره‌ی نقش «ناظر»
اگر دوست دارید قبل از انتشار خودکار، پست‌ها ابتدا برای تأیید شما (مثلاً در یک چت خصوصی) ارسال شوند و بعد از تأیید در کانال منتشر شوند، این قابلیت (حالت «تأیید دستی») را هم می‌توانم به همین اسکریپت اضافه کنم — کافی است بگویید.
